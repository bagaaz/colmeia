# Colmeia Web

Site institucional estático da Colmeia Web, agência de gestão de tráfego pago e anúncios digitais. A página e os recursos ficam em `public/`.

## Visualizar localmente

Com Python 3 instalado, execute na raiz do clone.

```bash
python3 -m http.server 8000 --directory public
```

Abra [http://localhost:8000](http://localhost:8000).
